# learning-lab

Личная учебная лаборатория на основе скилла [`teach` Мэтта Покока](https://github.com/mattpocock/skills/tree/main/skills/productivity/teach). Claude учит теме урок за уроком: миссия задаёт направление, знания берутся только из проверенных источников, каждый урок — короткий HTML с практикой и мгновенной обратной связью. Всё состояние хранится в файлах этого репозитория, поэтому любая новая сессия — в чате, в Claude Code, на другом устройстве — продолжает курс, а не начинает заново.

Репозиторий — это одновременно:

- **плагин `lab`** (`plugin/`) — скиллы `teach`, `review`, `assess`;
- **маркетплейс** (`.claude-plugin/marketplace.json`) — чтобы ставить плагин одной командой;
- **лаборатория** (`dashboard.md`, `courses/`, `assets/`, `review/`) — мои темы, уроки и прогресс.

## Установка

**claude.ai и десктоп-приложение:** Customize → Plugins → Add → Add marketplace → `kxnzee/learning-lab` → установить `lab`. Для приватного репозитория нужен подключённый GitHub; иначе — Add → Upload plugin с архивом папки `plugin/`. Плагин сам появится и в Claude Code.

**Claude Code:**

```
/plugin marketplace add kxnzee/learning-lab
/plugin install lab@learning-lab
```

На вкладке Connectors плагина подключите DeepWiki — через него удобно задавать вопросы по чужим репозиториям.

## Как учиться

Говорите обычными словами — скиллы срабатывают по смыслу. В Claude Code их можно вызвать и командой (`/lab:teach harness`).

| Что сказать | Скилл | Что происходит |
|---|---|---|
| «хочу изучить X» | `teach` | интервью о миссии → диагностика уровня → поиск источников → первый урок |
| «следующий урок по harness», «давай учиться» | `teach` | выбор шага в зоне ближайшего развития: новый урок, тренировка или реальная практика |
| «что повторить?» | `review` | карточки, у которых подошёл срок |
| «я уже освоил?», «проверь меня» | `assess` | проверка критерия успеха из миссии → что дальше |

В чате Claude подключает этот репозиторий, читает состояние темы и в конце коммитит изменения — для этого ему нужен доступ на запись.

## Устройство

```
dashboard.md                 все темы: статус, последний урок, что дальше, очередь
assets/                      общие компоненты уроков: lab.css, quiz.js
review/cards.md              карточки повторения (Лейтнер, 6 коробок)
courses/<тема>/              одна тема — одна миссия
  MISSION.md                 зачем и критерии успеха (чек-лист)
  RESOURCES.md               источники: Знание / Мудрость / Пробелы
  GLOSSARY.md                язык темы
  learning-records/          что я доказанно знаю (как ADR)
  lessons/NNNN-*.html        уроки
  reference/*.html           шпаргалки, к которым возвращаюсь
  lab/                       мой код и эксперименты
  NOTES.md                   как мне удобнее учиться
plugin/                      плагин lab: skills/{teach,review,assess}, хук, коннектор
tests/                       тесты скрипта повторения
```

## Что взято у Мэтта Покока и что добавлено

Основа — модель `teach`: миссия, источники высокого доверия вместо памяти модели, Знание → Навык → Мудрость, прочность хранения вместо беглости, зона ближайшего развития, уроки-HTML с компонентами, reference, learning records, glossary.

Добавлено там, где документация `teach` сама называет пробелы:

| Пробел в `teach` | Решение здесь |
|---|---|
| Нет оценки стартового уровня ([#725](https://github.com/mattpocock/skills/issues/725)) | Диагностика 3–5 вопросами при заведении темы → learning records о знаниях и пробелах |
| Нет интервального повторения | Скилл `review` и `cards.py`: карточки после каждого урока, Лейтнер; разминка-вспоминание в начале каждого урока |
| Не знает, когда остановиться и перейти к повторению или практике | Критерии успеха миссии как чек-лист; `teach` выбирает между уроком, тренировкой и практикой; `assess` отмечает критерии по доказательствам |
| Правильный ответ квиза всегда первый ([#335](https://github.com/mattpocock/skills/issues/335)) | `quiz.js` перемешивает варианты при показе |
| Файлы курса пишутся в папку скилла ([#377](https://github.com/mattpocock/skills/issues/377)) | Явно разделены «папка скилла — только чтение» и «лаборатория — сюда пишем» |
| Glossary не подключён ([#559](https://github.com/mattpocock/skills/issues/559)) | GLOSSARY.md — часть каждой темы |
| Одна миссия на папку | Много тем в `courses/` под общим дашбордом, общий стиль уроков |

## Разработка плагина

```bash
python3 -m pytest tests/                    # тесты cards.py
claude plugin validate .                    # проверка маркетплейса и плагина
claude --plugin-dir ./plugin                # сессия с локальной копией плагина
```

После изменений в `plugin/` поднимайте `version` в `plugin/.claude-plugin/plugin.json`. Если меняете `plugin/skills/teach/starter-assets/`, скопируйте их и в `assets/`.
