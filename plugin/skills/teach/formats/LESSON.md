# Формат урока

Урок — главное, что ты создаёшь: единица, через которую знание и навык доходят до ученика. Один самодостаточный HTML-файл в `courses/<slug>/lessons/NNNN-<slug>.html`, номер — наибольший существующий плюс один.

## Требования

- **Одна узкая вещь, одна ощутимая победа.** После урока ученик умеет что-то, чего не умел, и это шаг к критерию успеха из MISSION.md. Урок проходится за один присест: рабочая память маленькая, не перегружай.
- **Сначала знание, потом навык.** Ровно столько знания, сколько нужно для навыка урока, затем практика с петлёй обратной связи.
- **Разминка-вспоминание.** Первым блоком 1–3 вопроса по прошлым урокам этой темы (компонент `.recall`): ответ по памяти, до любой подсказки. Это интервалы и вспоминание внутри урока.
- **Цитаты.** Каждое утверждение — со ссылкой на источник из RESOURCES.md. Урок без ссылок — урок из памяти модели.
- **Один главный источник.** Рекомендуй ученику прочитать или посмотреть самый надёжный источник по теме урока.
- **Практика.** Квиз (`.quiz`), вспоминание (`.recall`), задание в `lab/` с критерием «готово», или пошаговые действия в реальном мире. Задание в `lab/` ученик выполняет сам и присылает на ревью.
- **Ссылки.** На соседние уроки и документы `reference/` — обычными HTML-якорями с относительными путями.
- **Напоминание**: вопросы по уроку задавай преподавателю в чате — он поможет со всем, что непонятно.
- **Термины** — строго по GLOSSARY.md; новый термин определяется прямо в уроке при первом появлении.
- **Красиво.** Чистая типографика и вёрстка в духе Тафти: к урокам возвращаются.

## Компоненты

Уроки собираются из общих компонентов в `<лаборатория>/assets/` — так все темы выглядят как один курс. Перед уроком прочитай, что там есть, и строй из этого. Нужно новое и пригодится второму уроку — оформи компонентом в `assets/` (общий для всех тем) или в `courses/<slug>/assets/` (только для темы), а не встраивай в урок.

Подключение из `courses/<slug>/lessons/`:

```html
<link rel="stylesheet" href="../../../assets/lab.css">
<script src="../../../assets/quiz.js" defer></script>
```

### Квиз

```html
<div class="quiz">
  <p class="q">Кто выполняет инструмент, который выбрала модель?</p>
  <button data-correct>Харнес, затем возвращает результат модели</button>
  <button>Модель, внутри собственного контекста</button>
  <button>Провайдер API, на своей стороне</button>
  <p class="why">Модель только выбирает инструмент и аргументы; выполняет харнес.</p>
</div>
```

`quiz.js` перемешивает варианты при показе — порядок в разметке значения не имеет. Варианты одинаковой длины и структуры: ни длина, ни формулировка не должны подсказывать ответ.

### Вспоминание

```html
<div class="recall">
  <p class="q">Своими словами: зачем харнесу ограничивать число шагов цикла?</p>
  <p class="answer">Чтобы зацикленная модель не тратила бюджет бесконечно; лимит — предохранитель.</p>
</div>
```

Ученик пишет ответ, затем открывает эталон и сам оценивает: «вспомнил / частично / нет».

## Скелет

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>NNNN · {название}</title>
  <link rel="stylesheet" href="../../../assets/lab.css">
  <script src="../../../assets/quiz.js" defer></script>
</head>
<body>
<main class="lesson">
  <header>
    <p class="kicker">{тема} · урок NNNN</p>
    <h1>{название}</h1>
    <p class="win">После урока вы сможете: {одна ощутимая победа}</p>
  </header>
  <section><h2>Разминка</h2> {recall по прошлым урокам} </section>
  <section><h2>{знание}</h2> {коротко, со ссылками} </section>
  <section><h2>Практика</h2> {квиз, recall, задание в lab/} </section>
  <aside class="source">Главный источник: <a href="…">…</a></aside>
  <footer>Вопросы по уроку — задавайте преподавателю в чате. ← <a href="NNNN-prev.html">предыдущий</a> · <a href="../reference/…">справочник</a></footer>
</main>
</body>
</html>
```
