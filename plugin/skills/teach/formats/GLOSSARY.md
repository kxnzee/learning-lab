# Формат GLOSSARY.md

`courses/<slug>/GLOSSARY.md` — канонический язык темы. Уроки, задания, learning records и reference используют его термины. Сжать понятие в точное определение — само по себе доказательство понимания.

## Шаблон

```md
# Глоссарий: {тема}

{Одно-два предложения о том, что покрывает глоссарий.}

## Термины

**Agent loop (агентный цикл)**:
Цикл, в котором модель выбирает инструмент, харнес его выполняет и возвращает результат модели — до тех пор, пока модель не ответит без вызова инструмента.
_Не использовать_: главный цикл, run loop
```

## Правила

- **Термин попадает сюда, когда ученик им правильно пользуется.** Глоссарий — запись сжатого знания, а не словарь для заучивания.
- **Будь категоричен.** Несколько слов для одного понятия — выбери лучшее, остальные в «Не использовать».
- **Коротко.** Одно-два предложения: что это ЕСТЬ, а не как это делать.
- **Термины глоссария — внутри определений тоже.** Так сложное понятие опирается на уже знакомые.
- **Английский термин — как есть**, русский перевод в скобках, если он устоялся.
- **Неоднозначность — явно.** «В этой теме "скилл" — всегда Agent Skill с SKILL.md, а не навык ученика».
- **Пересматривай.** Определение первой недели может оказаться неверным к шестой — правь на месте.
