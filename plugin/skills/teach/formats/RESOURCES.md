# Формат RESOURCES.md

`courses/<slug>/RESOURCES.md` — отобранные источники по теме. Знание для уроков берётся отсюда, а не из памяти модели. Мудрость — из сообществ, перечисленных здесь.

## Шаблон

```md
# Источники: {тема}

## Знание

- [Спецификация: A2UI v0.8](https://a2ui.org/)
  Первоисточник протокола. Использовать для: структура сообщений, каталог компонентов.
- [Репозиторий: shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)
  20 уроков от агентного цикла до харнеса. Использовать для: порядок модулей, эталонный код.

## Мудрость (сообщества)

- [GitHub Discussions проекта](https://example.com)
  Использовать для: вопросы к авторам, разбор чужих решений.

## Пробелы

- {Область, нужная миссии, для которой хорошего источника пока нет}
```

## Правила

- **Только высокое доверие.** Первоисточники: спецификации, официальная документация, репозиторий проекта, авторы. Маркетинг под видом обучения — мимо.
- **Свежесть.** Темы лаборатории быстро меняются: у источника по быстро развивающейся технологии должна быть видна дата или версия; устаревший — замени.
- **Подпиши каждую запись.** Одна строка: что внутри и когда к нему обращаться. Голая ссылка через три месяца бесполезна.
- **Знание / Мудрость.** Источник может быть только в одной группе.
- **Пробелы явно.** Чего не хватает миссии — в «Пробелы»; это задаёт будущий поиск.
- **Чисти без жалости.** Ошибочный, поверхностный или не по миссии источник удаляй. Пять точных лучше тридцати средних.
- **Сообщества по желанию.** Ученик отказался от сообществ — запиши это здесь, чтобы не предлагать снова.
