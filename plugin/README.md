# Learning Lab (`lab`)

Плагин для самостоятельного изучения технологий и любых других тем, основанный на скилле `teach` Мэтта Покока. Claude выясняет, зачем вам тема, проверяет стартовый уровень, находит источники высокого доверия и ведёт короткими HTML-уроками с практикой и мгновенной обратной связью. Состояние — миссия, learning records, уроки, справочники, карточки повторения — хранится в файлах учебной лаборатории (папка с `dashboard.md` и `courses/`), поэтому каждая сессия продолжает предыдущую.

## Скиллы

- `teach` — новая тема (миссия, диагностика, источники) и следующий шаг: урок, тренировка или реальная практика;
- `review` — интервальное повторение по системе Лейтнера (`scripts/cards.py`);
- `assess` — проверка критерия успеха из миссии и решение, что дальше.

## Данные

Плагин читает и пишет только файлы лаборатории. Хук `SessionStart` (только в Claude Code) читает `review/cards.md` и показывает число карточек к повторению. Коннектор DeepWiki (`mcp.deepwiki.com`) получает названия публичных репозиториев и вопросы о них, когда вы его используете.
